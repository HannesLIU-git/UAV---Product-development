# UAV Product Development

Detta repository används för att planera, utveckla, verifiera och dokumentera en UAV från idé till drift och vidare underhåll.

## Projektets mål

> Fyll i en kort och mätbar beskrivning av vad UAV:n ska kunna göra, för vem och under vilka förutsättningar.

## Utvecklingsmodell

Projektet följer en fasindelad process:

1. Projektstart och organisation
2. Behov, användningsfall och krav
3. Konceptstudie och genomförbarhet
4. Systemarkitektur och preliminär design
5. Detaljkonstruktion
6. Prototyp och integration
7. Verifiering, validering och flygprov
8. Produktion, drift och underhåll
9. Avveckling och lessons learned

## Dokumentationsregler

- Använd Markdown för textdokument.
- Lägg ett versionsnummer, datum, status och ansvarig i varje viktigt dokument.
- Håll krav spårbara från behov till testresultat.
- Lägg inte hemligheter, API-nycklar, personuppgifter eller flygsäkerhetskänslig information i klartext.
- Använd pull requests för större ändringar.
